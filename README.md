
# Class Codex Continued

> **⚠️ Not ready for use.** The data-refresh pipeline that kept `Data/` current
> is being rebuilt from scratch — see [Data pipeline](#data-pipeline) below.
> The bundled talent builds, gear recommendations, and stat priorities were
> last scraped by the original author's (lost) tooling on **2026-07-02** and
> will only get staler until that pipeline is back. Don't rely on this addon
> for current information yet.

Class Codex gives you stat priorities, talent builds, rotation guides, and
gearing recommendations for your current spec — right inside the game, sourced
from Wowhead, Icy Veins, Archon.gg, Murlok.io, and Battle.net.

## Background

Class Codex was originally developed by **jfstn** and published on CurseForge
(project ID `1480030`). That listing no longer exists. This repository is an
unaffiliated continuation, picking the addon back up under the same
[MIT license](LICENSE) it always carried.

## Supported Game Versions

Retail only (`ClassCodex.toc`, Interface 120007 / WoW 12.0.7). The next goal is
verifying and updating everything for the WoW 12.1 content patch — see
[Data pipeline](#data-pipeline).

## Project Structure

| Path | Contents |
| --- | --- |
| `ClassCodex.lua` | Core addon lifecycle, panel, saved variables |
| `Data/<Class>/` | Per-spec talent builds, gear, stats, and sources — see below |
| `Sections/` | Panel tabs (Rotation, Talents, Gear, Stats, Crafting, Trinkets, etc.) |
| `Shared/` | Cross-section helpers (import/export, PvP data, gearing utils, taint reduction) |
| `UI/` | Reusable widgets (collapsible sections, tooltips, slot icons) |
| `Locales/` | Translated strings (10 locales) |
| `Libs/` | Vendored third-party libraries — see [Libs/README.md](Libs/README.md) |
| `packages/bot/` | Original author's Discord server setup script (prototype tooling, not part of the packaged addon) |
| `packages/wcl-diff/` | Original author's WarcraftLogs API exploration scripts (prototype tooling, not part of the packaged addon) |

Each `Data/<Class>/sources.lua` records the exact Wowhead/Icy Veins/Archon.gg/
Murlok.io URL each spec's data came from — that's the map for rebuilding the
scraper (see below).

## Data pipeline

`Data/Generated.lua` says "generated by the scraper. Do not edit by hand" —
but the scraper itself was never committed to this repo, so it's being rebuilt
from scratch. Design:

- A new `packages/scraper` package, one adapter per source site (Wowhead, Icy
  Veins, Archon.gg, Murlok.io, Battle.net PvP talents), reading the URLs
  already recorded in each `Data/<Class>/sources.lua` and writing the same Lua
  table shapes the current `Data/*.lua` files already use.
- A scheduled GitHub Action runs the scraper (weekly, after the Tuesday reset)
  and opens a pull request with the regenerated diff, rather than pushing
  straight to `main` — the source sites can change layout without notice, and
  this data reaches players directly, so a human reviews every refresh before
  it ships.
- See the `v0.38.0` milestone and its issues in this repo for current status.

## Development

```sh
luarocks install luacheck
luacheck .
```

Runs on every push and pull request via
[.github/workflows/ci.yml](.github/workflows/ci.yml), alongside a packager
dry-run. Pushing a `v*` tag builds the release zip with the
[BigWigs packager](https://github.com/BigWigsMods/packager); `.pkgmeta`
excludes `packages/` (the TS tooling above) from the shipped addon.
